# 01 — Project Overview

## Vision

`xtrading` is a responsive stock trading dashboard that lets a user track markets,
manage a watchlist, view a portfolio, and explore interactive price charts. It is
built primarily as a **portfolio project** to demonstrate modern front-end skills.

## Goals

- Showcase a clean, modern, professional fintech UI (dark-first).
- Be fully **responsive** — usable on both desktop and mobile.
- Demonstrate solid front-end architecture: Vue 3, TypeScript, Pinia, component reuse.
- Prioritize a polished UX over breadth of features.

## Target users

- Recruiters / hiring managers reviewing the project.
- A hypothetical retail investor tracking stocks and a portfolio.

## In scope (v1)

- Watchlist, Portfolio, Chart, Markets, News pages.
- Responsive shell: left sidebar (desktop) → bottom tab bar (mobile).
- Mock/static market data first; real API integration later.

## Out of scope (for now)

- Real money / real brokerage execution (Buy/Sell is simulated).
- User authentication backend (may add a mock auth later).
- Real-time streaming data at launch (polling/mock first).

## Success criteria

- Looks and feels like a real trading app on desktop and mobile.
- Code is clean, typed, and easy to navigate.
- Layout shell and core reusable components are solid and consistent.
